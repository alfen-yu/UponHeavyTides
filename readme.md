# Upon Heavy Tides

### Description 
Upon Heavy Tides is a single-player 3D underwater adventure built in Unity. A student who has given up on becoming a marine biologist falls asleep over his homework and wakes in a fading underwater kingdom. He explores zones from the sunlit shallows to the abyss, uses stealth and physics puzzles to get past predators, and records clues in a notebook that slowly sketches the monster behind the darkness.

### Tech Involved 
- Unity: 6000.3.13f1
- Unity Input System Package (Keyboard & Mouse)
- Unity AI Navigation (NavMesh)

### Controls
- **Move:** Arrow Keys (or WASD)
- **Turn Camera:** A (turn right) / D (turn left)
- **Jump:** Space
- **Interact / Talk:** E or Enter
- **Push Stones:** Walk into stones

### Folder Structure 
- **Assets/Scripts:** C# Scripts (Player, Level0, GameAI, Interaction)
- **Assets/Scenes:** Level 0 (The Shallows), Level 1 (The Kelp Maze)
- **Assets/Materials:** Underwater surfaces and shaders
- **Assets/Editor:** Level 0 & Level 1 procedural scene builders
- **GAMEPLAY_AND_FLOW_GUIDE.md:** Full design, mechanics, and walkthrough documentation

# Upon Heavy Tides


### Description 
Upon Heavy Tides is a single-player 3D adventure built in Unity. A student who has given up on becoming a marine biologist falls asleep over his homework and wakes in a fading underwater kingdom. He explores zones from the sunlit shallows to the abyss, uses stealth and physics puzzles to get past predators, and records clues in a notebook that slowly sketches the monster behind the darkness. His choices change the final boss fight.
